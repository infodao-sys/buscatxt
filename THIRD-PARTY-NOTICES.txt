Included in: buscatxt-windows-x86_64.exe (version 0.4.1 and later).

3. References (no third-party code was copied)
----------------------------------------------

These works were consulted as references. buscatxt contains its own
independent implementations; no source code from them is included.

- DEFLATE decompressor (src/docs/inflate.rs): written following the
  structure of "puff", the reference DEFLATE decoder included with zlib,
  Copyright (C) 2002-2013 Mark Adler, zlib License.
  https://github.com/madler/zlib/tree/master/contrib/puff

- Date conversion for Excel serial numbers (src/docs/office.rs):
  "civil_from_days" algorithm by Howard Hinnant, placed in the public
  domain. https://howardhinnant.github.io/date_algorithms.html

- File format specifications:
  * RFC 1950 (zlib) and RFC 1951 (DEFLATE).
  * PKWARE APPNOTE.TXT (ZIP file format).
  * ECMA-376 / ISO/IEC 29500 (Office Open XML: DOCX, XLSX, PPTX).
  * OASIS OpenDocument v1.3 (ODT, ODS, ODP).
  * ISO 32000 (PDF) and the Adobe Glyph List.
  * Microsoft Open Specifications: [MS-CFB], [MS-DOC], [MS-XLS], [MS-PPT].


4. Operating system libraries (not distributed)
-----------------------------------------------

At run time the executables use system libraries that are part of the
operating system and are not distributed with buscatxt:
- Linux: GNU C Library (glibc, LGPL-2.1+) and libgcc_s (GPL-3.0 with the
  GCC Runtime Library Exception).
- Windows: KERNEL32.dll, ntdll.dll, msvcrt.dll, bcryptprimitives.dll and
  api-ms-win-core-synch-l1-2-0.dll (Microsoft Windows components).
